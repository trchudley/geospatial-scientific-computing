# Introduction

Week 8 introduces Google Earth Engine as one method for performing large-scale cloud computing.

:::{tip} Learning Objectives
After this session, you should be able to
 - Understand how to access GEE and search and download data within it.
 - Construct large-scale composite imagery across space and time.
 - Construct large-scale time-series records across space and time.
:::
