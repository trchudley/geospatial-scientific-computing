## Submitting code for your final project

Include a reasonable `README.md`, `environment.yml`, `LICENCE` file, and `.gitignore` file. You are welcome to choose a less permissive license, but is there any point? Try and seperate your directories by `notebooks`, `figures`, and `data`. 

Noteebooks should have clear file and variable names. Path managment should be done using relative links so that they do not break on someone elses PC.

If your gridded datasets are very large, `.gitignore` should include `.tif` and `.nc` files.


You are welcome to submit your code as:

1. a zip file, within blackboard. The title of the `zip` file should be your student number.
2. your own private repository, linked to from your report.
3. if you are comfortable doing so, make a pull request to the github repository `trchudley/geogm0081-submission-repo-2026`.

Fork this repository, and submit your code within a directory titled by your student number.
